# 소개 사이트 디자인 토큰

`site/site.css`(포트폴리오 첫 화면 `index.html`, 공고 항목별 근거 `fit.html`)와 `site/docs/doc.css`(문서 페이지)가 쓰는 색, 글꼴, 간격 값입니다.

2026-11-21에 어두운 바탕 + 보라색 강조에서 밝은 바탕 + 파란색 한 가지로 바꿨습니다. 디자이너 포트폴리오처럼 '문제 정의 → 해결 → 결과' 순서로 읽히게 하고, 글보다 그림(비교 카드, 막대, 숫자)이 먼저 보이게 하려는 것입니다.

## 색

| 토큰 (site.css) | 문서 페이지 (doc.css) | 값 | 쓰는 곳 |
|---|---|---|---|
| `--brand` | `--primary` | `#1b5be6` | 첫 화면 바탕, 주 버튼, 강조 글자. 흰 글씨 대비 5.7:1 |
| `--brand-dark` | `--primary-hover` | `#1447bd` | 버튼을 눌렀을 때, 문서의 링크 글자 (흰 바탕 대비 7.6:1) |
| `--brand-soft` | | `#ecf2ff` | 칩, 강조 칸 바탕 |
| `--ink` | `--ink` | `#191f28` | 제목, 굵은 글자 |
| `--ink-2` | `--ink-muted` | `#4e5968` / `#333d4b` | 본문 |
| `--ink-3` | `--ink-subtle` | `#5b6573` | 작은 글씨. 흰 바탕과 연회색 바탕 모두 4.5:1 이상 |
| `--line` | `--hairline` | `#e5e8eb` | 카드 테두리, 구분선 |
| `--bg-soft` | `--surface-2` | `#f4f6f9` / `#f2f4f6` | 번갈아 쓰는 절 바탕, 표 머리 |
| `--bg-dark` | | `#191f28` | 맨 아래 링크 모음 |
| `--red` | `--danger` | `#d92d33` | 결함 예시의 '틀린 값' |
| `--green` | `--success` | `#0b7d43` | 통과 표시 |

강조색은 파란색 하나입니다. 보라색, 그라디언트 글자, 어두운 바탕의 빛나는 테두리는 쓰지 않습니다.

## 글꼴

| 토큰 | 값 |
|---|---|
| `--font` (site.css), `--font-text` (doc.css) | Pretendard Variable (jsDelivr), 없으면 Apple SD Gothic Neo, 맑은 고딕 |
| `--mono`, `--font-mono` | 시스템 고정폭 글꼴 |

| 쓰는 곳 | 크기 |
|---|---|
| 첫 화면 제목 (h1) | 56px (768px 아래 40px) |
| 절 제목 (h2) | 34px (768px 아래 26px). 두 줄로 나누고 뒷줄을 파란색으로 |
| 절 설명 (`.lead`) | 17px, 한 줄 약 40자 |
| 숫자 띠 (`.stat-num`) | 38px |
| 카드 제목 (h3) | 18~19px |
| 본문, 카드 글 | 15~16px |
| 작은 글씨 | 13~14px |

## 간격과 모서리

| 토큰 | 값 |
|---|---|
| `--wrap` | 1120px (좌우 여백 24px, 768px 아래 16px) |
| 절 사이 | 112px (768px 아래 80px) |
| `--r` | 16px (카드) |
| 버튼 | 높이 44px, 모서리 12px |

## 화면 폭

| 폭 | 바뀌는 것 |
|---|---|
| 1024px 이하 | 위쪽 메뉴의 절 이동 숨김, 첫 화면 1열(기기 화면은 글 아래), 숫자 띠 2열, 결함 사례 1열 |
| 768px 이하 | 카드 1열, 문제 → 해결 줄은 위아래로, 첫 화면 버튼은 2개씩 |
| 420px 이하 | 숫자 띠 1열, 첫 화면 버튼은 한 줄에 하나 |

## 자동으로 채우는 곳

`site/build-docs.mjs`가 `site/results/results.json`으로 다시 씁니다. 숫자를 손으로 고치지 않습니다.

| 파일 | 표시 | 내용 |
|---|---|---|
| `index.html` | `<!-- stats:… -->` | 첫 화면 아래 숫자 띠 |
| `index.html` | `<!-- devices:… -->` | 기기별 결과 막대 |
| `fit.html` | `<!-- fit:… -->` | 공고 항목 목록 (`requirements.mjs`) |

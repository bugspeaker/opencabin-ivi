# 소개 사이트 디자인 토큰

`site/index.html`과 `site/docs/doc.css`가 쓰는 색, 글꼴, 간격, 모서리 값입니다. 두 파일은 이 값만 씁니다.

## 색

어두운 바탕 위에 회색 글자를 두고, 강조색은 파란 보라 한 가지만 씁니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--canvas` | `#010102` | 페이지 바탕 |
| `--surface-1` | `#0f1011` | 카드, 패널 |
| `--surface-2` | `#141516` | 카드 안의 칸, 코드 블록, 마우스를 올린 카드 |
| `--surface-3` | `#18191a` | 더 깊은 칸 |
| `--hairline` | `#23252a` | 카드 테두리, 구분선 |
| `--hairline-strong` | `#34343a` | 강조 테두리, 구조도의 상자 |
| `--ink` | `#f7f8f8` | 제목, 본문 강조 |
| `--ink-muted` | `#d0d6e0` | 본문, 근거 설명 (바탕 대비 약 13:1) |
| `--ink-subtle` | `#8a8f98` | 작은 글씨, 번호, 코드 주석 (바탕 대비 약 6:1) |
| `--ink-tertiary` | `#62666d` | 장식(제목 옆 `#` 표시, 목록 점)에만. 글자에는 쓰지 않음 (대비 약 3.6:1) |
| `--primary` | `#5e6ad2` | 주 버튼, 브랜드 표시 |
| `--primary-hover` | `#828fff` | 링크, 구조도의 화살표, 버튼에 마우스를 올렸을 때 |
| `--semantic-success` | `#27a644` | 상태 점 |

작은 글씨(16px 미만)는 `--ink-subtle` 이상만 씁니다. WCAG AA 기준(4.5:1)을 넘기려는 것입니다.

## 글꼴

| 토큰 | 값 |
|---|---|
| `--font-display`, `--font-text` | Inter (Google Fonts), 없으면 시스템 글꼴 |
| `--font-mono` | JetBrains Mono, 없으면 시스템 고정폭 글꼴 |

제목 위계는 h1(`display-xl`, 56px) > 공고 목차 제목(`display-lg`, 48px) > 섹션 제목(`display-md`, 40px)입니다. 1024px 아래에서는 48 / 40 / 40px, 768px 아래에서는 36 / 32 / 28px로 줄입니다.

| 클래스 | 크기 | 쓰는 곳 |
|---|---|---|
| `headline` | 28px | 지표 카드 숫자, 배너 제목 |
| `card-title` | 22px | 카드 제목 |
| `body-lg` | 18px | 섹션 설명 |
| `fit-done` | 15px | 공고 항목의 근거 설명 |
| `body-sm` | 14px | 카드 본문 |
| `eyebrow` | 13px | 섹션 위의 작은 제목 |
| `caption` | 12px | 캡션 |

## 간격과 모서리

| 토큰 | 값 |
|---|---|
| `--s-xxs` ~ `--s-xxl` | 4, 8, 12, 16, 24, 32, 48px |
| `--s-section` | 96px (섹션 사이) |
| `--r-xs` ~ `--r-xl` | 4, 6, 8, 12, 16px |
| `--r-pill` | 9999px |

## 화면 폭

| 폭 | 바뀌는 것 |
|---|---|
| 1024px 이하 | 위쪽 메뉴 숨김, 공고 목차 1열, 카드 2열, 지표 카드 2열 |
| 768px 이하 | 좌우 여백 16px, 카드 1열, 버튼 높이 44px |
| 480px 이하 | 지표 카드는 2열 그대로, 글자와 여백만 줄임 |

구조도(SVG)는 760px보다 좁으면 그림 안에서만 가로로 밀어 봅니다. 페이지 전체가 가로로 밀리지는 않습니다.

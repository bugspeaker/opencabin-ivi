#전체 실행 기록

근거 자료에 결과 파일(원자료)이 남은 E2E 실행을 모두 합친 기록입니다(2026년 11-18부터 11-24까지). ivi-tests/tools/run_history.py가 결과 파일에서 다시 세어 만듭니다. 결과 파일을 남기기 전인 11-13부터 11-17까지의 실행은 들어 있지 않습니다.

실패, 오류, 재시도 후 통과는 하나도 빼지 않고 원인과 함께 적었습니다. 다만 판정 기능을 확인하려고 앱을 일부러 죽인 실행(2회)은 합계에서 빼고 아래 표에만 둡니다. 세션을 일부러 끊은 실행은 그 상황에서도 끝까지 통과하는지 본 것이라 합계에 넣었습니다.

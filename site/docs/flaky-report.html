#읽는 법과 한계

  • flaky는 첫 시도에 실패하고 재시도(--reruns 1)에서 통과한 것입니다. 통과로 치지 않고 따로 셉니다.
  • 아래 flaky_report.py 출력의 '평균 테스트 시간 합'은 테스트별 시간의 합이라, 세션 전체 시간(Appium 연결, 앱 시작 포함)인 위 표보다 짧습니다.
  • 같은 PC, 같은 날 저녁의 5회입니다. 기간에 걸친 추세, 다른 PC나 다른 기기 상태에서의 흔들림은 이 표에 없습니다.
  • 11-18 마지막 회차의 판정과 화면은 결과 페이지에서 2026-11-21 3회차로 바뀌었습니다. 이 회차의 결과 파일은 원자료 폴더에 있습니다. 실패가 나면 저장되는 자료의 예시는 실패 자료 한 묶음입니다.
  • 2026-11-19 정정: 처음 올린 아래 절은 --last 5로 누적 기록을 읽어, 5회차 뒤에 따로 돌린 15개짜리 실행(20261118-204700)이 1회차 대신 섞여 있었습니다(평균 테스트 시간 합 458초, 432초). 원자료 10개만 읽도록 다시 만들었습니다. flaky 0, 실패 0은 그대로입니다.

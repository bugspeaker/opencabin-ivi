# 반복 실행 통계

두 기기(AAOS 에뮬레이터, 화웨이 태블릿)에서 E2E 전체를 병렬로 반복한 기록입니다. 가장 최근은 2026-11-24에 주행 상태 읽기를 고친 테스트 코드와 테스트 144개로 돌린 3회이고, 그 아래에 2026-11-23 저녁의 144개 3회, 같은 날 오후의 140개 3회, 2026-11-21의 129개 3회, 2026-11-18의 5회 기록을 그대로 두었습니다. 첫 시도와 확인용 실행까지 모두 합친 수와 실패마다의 원인은 [전체 실행 기록](run-history.md)에 있습니다.

### 읽는 법과 한계

- flaky는 첫 시도에 실패하고 재시도(`--reruns 1`)에서 통과한 것입니다. 통과로 치지 않고 따로 셉니다.
- 아래 flaky_report.py 출력의 '평균 테스트 시간 합'은 테스트별 시간의 합이라, 세션 전체 시간(Appium 연결, 앱 시작 포함)인 위 표보다 짧습니다.
- 같은 PC, 같은 날 저녁의 5회입니다. 기간에 걸친 추세, 다른 PC나 다른 기기 상태에서의 흔들림은 이 표에 없습니다.
- 11-18 마지막 회차의 판정과 화면은 결과 페이지에서 2026-11-21 3회차로 바뀌었습니다. 이 회차의 결과 파일은 원자료 폴더에 있습니다. 실패가 나면 저장되는 자료의 예시는 [실패 자료 한 묶음](samples/off-grid-temperature-aaos/)입니다.
- 2026-11-19 정정: 처음 올린 아래 절은 `--last 5`로 누적 기록을 읽어, 5회차 뒤에 따로 돌린 15개짜리 실행(`20261118-204700`)이 1회차 대신 섞여 있었습니다(평균 테스트 시간 합 458초, 432초). 원자료 10개만 읽도록 다시 만들었습니다. flaky 0, 실패 0은 그대로입니다.

# 소개 사이트 화면 확인 (2026-11-20)

외부 검토(F10)에서 '소스 설정만으로 모바일 터치, 키보드 포커스, hover 대비, 실제 줄바꿈까지 확인했다고 볼 수는 없다'는 지적을 받아, 사이트를 브라우저(Playwright, Chromium)로 열어 확인한 결과입니다. 이 PR에서 만든 `site/`를 로컬 파일로 열었고, 화면은 기기 배율 2로 찍었습니다.

## 확인한 것

| 확인 | 결과 |
|---|---|
| 페이지 전체 가로 넘침 (390, 768, 1440px × 첫 화면, 테스트 결과, README, 포트폴리오, 추적표) | 15곳 모두 없었습니다. |
| 페이지 안쪽 가로 스크롤 (표, 코드, 구조도) | README 1~2개, 포트폴리오 390px에서 4개. 넓은 표와 코드가 자기 칸 안에서 스크롤되는 것이고, 페이지는 넘치지 않았습니다. |
| 결과 페이지 필터·이동 버튼 높이 (390px) | 44px |
| 키보드 Tab 이동 | 첫 6개 요소 모두 2px 외곽선이 보임([focus-1440.jpg](focus-1440.jpg)) |
| 주 버튼 hover 바탕 | `rgb(75, 86, 193)` = `--primary-pressed`, 흰 글씨 대비 6.2:1 (전에는 `#828fff`, 2.9:1) |
| 공고 항목 → 근거 → 목차 복귀 | 목차의 'UI와 CarProperty/VHAL을 잇는 E2E' → `docs/test-results.html?req=e2e`(배너에 항목 이름) → '요구 역량 목차' 버튼 → `index.html#fit` |
| 첫 화면 소개 문단 폭 | 38rem(한 줄 약 36자), 행간 1.6 ([index-1440.jpg](index-1440.jpg)) |

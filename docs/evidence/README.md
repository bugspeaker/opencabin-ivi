- '결과 커밋'은 실행이 끝난 뒤 결과 파일을 넣은 커밋입니다. 2026-11-20 이전 실행은 실행한 코드가 그 커밋과 같다는 기록이 없어서 테스트 코드를 미기록으로 둡니다.
- 2026-11-20 `20261120-202159`는 세션 복구 브랜치에서 돌았습니다. 그 브랜치는 `4fbd09f`(main, #14 병합)에서 갈라졌고, 실행 13분 뒤 세션 복구 변경을 `15c9684`로 커밋했습니다. Release 게이트 실행 완전성과 conftest 정리 순서를 바꾼 `de733dd`는 다른 브랜치(#17)에 있어 이 실행에 들어 있지 않습니다(`git merge-base --is-ancestor de733dd 15c9684`가 거짓). 실행 당시 작업 트리가 `15c9684`와 같다는 기록은 없습니다.
- APK와 실행 명령은 2026-11-20 이전 실행 모두 미기록입니다. 11-18 반복은 run id와 화면 경로로 `run_bench.py --repeat 5 --shots`까지, 11-20은 `--reruns 1`까지만 확인됩니다. 2026-11-21 실행부터 결과 파일에 커밋, 커밋하지 않은 변경 여부, APK sha256, 실행 명령, 종료 코드가 남고, Release 게이트가 회차·기기마다 같은 커밋과 같은 APK인지 확인합니다(`--commit`).
- 세션을 일부러 끊은 실행에 지금의 게이트를 돌리면 조건 1(일부만 실행), 3(flaky), 6(알려진 결함 테스트가 범위 밖)으로 막힙니다.
- 1,250건은 두 기기 × 5회에서 실제로 돈 테스트 수입니다. 기기 전용이라 건너뛴 것(회차마다 AAOS 1, 태블릿 7)은 빼고, 알려진 결함으로 xfail된 실행(AAOS 회차마다 1, 모두 5건)은 넣었습니다. flaky 0, 실패 0은 2026-11-18 하루, 같은 PC의 5회에서 본 값입니다.

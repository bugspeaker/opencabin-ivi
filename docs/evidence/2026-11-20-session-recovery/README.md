# Appium 세션 복구 확인 (2026-11-20)

2026-11-19에 막 켠 AAOS 에뮬레이터에서 UiAutomator2 계측 프로세스가 죽자, 실행 전체에서 하나뿐인 Appium 세션에 묶인 뒤의 테스트 129개가 모두 준비 단계 오류가 됐습니다. 그래서 테스트를 시작할 때마다 세션을 확인하고, 끊겼으면 다시 붙이도록 바꿨습니다(`ivi-tests/ivi/session.py`). 다시 붙인 일은 결과에 `session_restart`로 남깁니다.

바꾼 코드를 기기에서 일부러 끊어 확인한 결과(시나리오 A, B)와, 끊지 않고 두 기기 전체를 돌린 결과(C)입니다. 모두 `--reruns 1`(CI와 같은 재시도 1회)로 돌렸습니다.

| 시나리오 | 기기 | 끊은 방법 | 결과 |
|---|---|---|---|
| A (`20261120-session-a`) | AAOS 에뮬레이터 | 실행 45초, 120초에 UiAutomator2 서버 강제 종료(`am force-stop io.appium.uiautomator2.server`) | 38개 모두 통과(그중 재시도로 통과 3), 세션 재연결 3번, 실패 0 |
| B (`20261120-session-b`) | 화웨이 태블릿 | 실행 45초에 Appium 서버를 끄고 바로 다시 시작(5초 뒤 준비) | 38개 모두 통과(그중 재시도로 통과 1), 세션 재연결 1번, 실패 0 |
| C (`20261120-202159`) | 두 기기 병렬, 전체 129개 | 끊지 않음 (세션을 감싼 뒤에도 모든 테스트 경로가 그대로 도는지) | AAOS 127 통과, 1 건너뜀, 1 알려진 결함 (11분 6초) / 태블릿 122 통과, 7 건너뜀 (9분 4초). 재시도 0, 세션 재연결 0. Release 게이트 통과 (2026-11-20 이 기록을 남길 때 다섯 조건, 그 뒤 실행 완전성 조건을 더한 여섯 조건으로 다시 돌려도 통과) |

- A의 재연결 3번 가운데 1번은 제가 끊기 전이었습니다. 첫 테스트를 돌던 중에 계측 프로세스가 스스로 끝났고(Appium 로그 `The process has exited with code 255`), 시각으로 보면 첫 강제 종료(45초)보다 앞섭니다. 11-19와 같은 일이 막 켠 에뮬레이터에서 다시 일어난 것으로 보고, 그 원인은 아직 모릅니다.
- 테스트 도중에 끊기면 그 시도는 실패하고, 재시도를 시작할 때 세션이 다시 붙어 통과합니다. 이 경우 결과는 passed가 아니라 flaky로 남아 Release 게이트(지금 번호로 조건 3)에서는 막힙니다. 인프라가 흔들린 Release 후보는 통과시키지 않는다는 뜻입니다.
- 고치기 전이었다면 A는 첫 테스트부터, B는 서버를 다시 켠 뒤의 테스트가 모두 오류였을 것입니다(11-19 실행에서 실제로 그랬습니다).

## 다시 세기

`ivi-tests` 폴더에서 돌립니다.

```powershell
.venv\Scripts\python tools\flaky_report.py --runs-dir ..\docs\evidence\2026-11-20-session-recovery\runs
```

네 파일을 합쳐 실행한 테스트 326건, flaky 4, 실패 0, 세션 재연결 4(AAOS 3, 태블릿 1)가 나옵니다. flaky 4와 재연결 4는 모두 시나리오 A, B에서 나왔습니다. C만 Release 게이트로 보려면 아래처럼 run id를 고릅니다. 여섯 조건이 모두 통과합니다. A, B는 일부만 돌린 실행이라 조건 1(실행 완전성)과 3(flaky)으로 막힙니다.

```powershell
.venv\Scripts\python tools\release_gate.py --runs-dir ..\docs\evidence\2026-11-20-session-recovery\runs --runs 20261120-202159
```

재연결이 있었던 테스트는 '불안정 테스트' 표에 '세션 재연결' 열과 함께 올라옵니다.

## 옮기면서 바꾼 것

오류 메시지에 들어 있던 작업 PC의 사용자 폴더 경로(Appium 설치 위치)를 `%USERPROFILE%`로 바꿨습니다(3곳). 나머지는 그대로입니다.

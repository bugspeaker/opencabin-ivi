# 6단계 기능 확장: 내비 · 라디오 · 전화 · 설정 · 후방 카메라 · 음성

작성 2026-11-13. 양산 IVI(ccNC, Pleos Connect 포함)가 홈과 앱 바에 두는 기본 메뉴를 갖췄다.
화면 구조는 5단계 원칙을 그대로 따른다 (구조만 참고, 제조사 로고·제품명·서비스명·실제 지도 데이터는 쓰지 않음).

## 1. 기능과 테스트

| 기능 | 내용 | 차량 신호·주행 제한과 엮인 것 | 테스트 |
|---|---|---|---|
| 내비게이션 | 검색 → 미리 보기 → 안내(다음 안내, 남은 거리, 도착 예정) → 도착. 즐겨찾기(집·회사) | 남은 거리가 차량 속도 신호로 줄어든다. 주행 중 검색 입력 잠금, 즐겨찾기는 허용 | 6 |
| 라디오 | FM(0.1 MHz)/AM(9 kHz), 미세 조정, 방송국 찾기, 프리셋 6개 저장 | 오디오 소스 하나만 재생 (라디오 ↔ 음악) | 6 |
| 전화 | 블루투스 핸즈프리(가상): 최근 통화, 연락처, 키패드, 통화 화면 | 주행 중 키패드 잠금, 연락처 5개까지. 통화 중 오디오 일시 정지 → 끝나면 다시 재생 | 4 |
| 설정 | 볼륨, 밝기, 24시간 시계, 속도 단위(km/h ↔ mph), 도어 자동 잠금, 무드등, 초기화 | mph로 바꾸면 차량 속도 50 km/h가 31 mph로 보인다 | 5 |
| 후방 카메라 | 기어 R이면 모든 화면 위에 카메라 화면 + 주차 가이드 선 | 기어 신호(GEAR_SELECTION=R) 만으로 뜨고 사라진다 | 3 |
| 음성 | 상태 줄 '음성' → 명령 문장 4개 (인식된 문장을 누르는 것으로 대신) | "운전석 온도 24도" → 차량 공조 신호가 24.0°C로 바뀐다 | 5 |

- 기존 smoke의 탭 이동 테스트를 7개 탭으로 늘렸다.
- 전체: 31 → 64개 (AAOS 전용 6개 포함). 단위 테스트 25개.

## 2. 앱 구조 (파일을 기능별로 나눔)

```
ivi-app/app/src/main/java/dev/opencabin/ivi/
  state/SettingsStore.kt     저장 설정 (SharedPreferences + StateFlow): 볼륨·밝기·시계·단위·무드등·라디오 대역/주파수/프리셋
  state/CabinController.kt   화면이 함께 쓰는 상태와 규칙: 오디오 소스 하나, 통화 중 일시 정지, 경로 진행, 음성 명령
  ui/Theme.kt                색·공통 부품 (Panel, RoundButton, PillButton, ToggleRow, StepperRow)
  ui/Shell.kt                틀: 상태 줄, 주행 정보, 앱 바(7개), 통화 화면, 음성 패널, 후방 카메라, 밝기
  ui/Home.kt Navigation.kt Radio.kt Media.kt Phone.kt Climate.kt SettingsScreen.kt
ivi-app/app/src/debug/       TestHookReceiver: 테스트가 저장 설정을 초기화하는 입구 (release 에는 없음)
```

## 3. 테스트를 위해 앱에 넣은 것: 테스트 훅

- 저장 설정은 앱을 다시 켜도 남는다. 그래서 한 테스트에서 mph로 바꾸면 다음 테스트도 mph로 시작한다.
- `src/debug` 에만 `TestHookReceiver`를 두고, `app` 픽스처가 테스트마다 `am broadcast … test.RESET`으로 기본값으로 되돌린다.
  release 빌드에는 들어가지 않는다 (debug 소스 세트).
- 기기 차이: AAOS 에뮬레이터는 앱이 꺼져 있어도 브로드캐스트를 받지만(`-f 0x20`), 화웨이는 꺼진 앱에 전달하지 않는다
  (logcat `targets O+, restricted`). 그래서 앱을 띄운 뒤에 초기화한다. 설정은 화면에 바로 반영되므로 결과는 같다.

## 4. 회귀에서 잡은 것

| 증상 | 원인 | 처리 |
|---|---|---|
| 음성 "집으로 안내해줘" 후 `nav_dest_name`을 못 찾음 | 명령을 처리한 뒤에도 음성 패널이 남아 안내 화면을 가린다 (기능은 동작) | 앱 결함으로 수정: 명령을 처리하면 패널을 닫고, 결과는 상태 줄 알림(5초)으로. 회귀 테스트 `test_voice_panel_closes_after_command` 추가 |
| 통화 중 전화 화면을 못 엶 | 통화 화면이 위를 덮어 머리글(`phone_device`)이 안 보인다 | 테스트 계약 수정: 화면 객체가 통화 화면도 '전화 화면이 열림'으로 본다 |
| 태블릿에서 설정 초기화가 안 됨 | 화웨이가 꺼진 앱에 브로드캐스트를 전달하지 않음 | 위 3처럼 순서 변경 |
| 라디오 전원 버튼이 네모로 보임 | `⏻` 글자가 기본 글꼴에 없다 | `▶` / `■`로 변경 (화면 확인에서 발견) |

UiAutomator는 다른 요소에 가려진 요소를 화면 소스에 내지 않는다. 그래서 '가려짐'은 테스트에서 '요소 없음'으로 나타난다.
1단계의 버튼 겹침 결함과 같은 종류다. 실패 자료의 스크린샷으로 가려진 것인지 바로 구분할 수 있었다.
